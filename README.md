# NY Lead Service Lines — Density Heatmap

Zoomable heatmap of confirmed customer-side lead service lines across New York State, built for embedding on a news site.

Source data: NY statewide lead service line inventory (`lead_pipes_ny_20260724`). Shows 282,582 records where the customer-owned portion of the service line is confirmed lead.

Live: https://benjys121.github.io/ny-lead-heatmap/

## Embedding

```html
<iframe src="https://benjys121.github.io/ny-lead-heatmap/" style="width:100%;height:600px;border:0" allow="fullscreen"></iframe>
```

## Controls

- Scroll/pinch + Ctrl/⌘ to zoom, or use the +/− buttons
- Click-drag (or one-finger touch once two fingers are down) to pan
- Reset button returns to the full-state view
